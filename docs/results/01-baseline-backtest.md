# 基线回测报告：双策略对比

- 日期：2026-08-12
- 回测区间：2024-01-01 → 2026-08-11（约 2 年 7 个月）
- 数据：OKX 现货 1h K 线，BTC/ETH/SOL/XRP 对 USDT
- 资金假设：初始 10000 USDT，单笔 500 USDT，最多同时 3 仓
- 费用假设：OKX 默认现货费率（约 0.1%/边），限价单进出
- 同期市场基准（四对均值买入持有）：**+17.34%**

## 核心指标对比

| 指标 | EmaRsiStrategy（趋势跟随） | RsiMeanRevertStrategy（均值回归） |
|---|---|---|
| 总收益 | **-11.90%**（-1190 USDT） | **-1.22%**（-122 USDT） |
| CAGR | -4.74% | ≈ -0.5% |
| 交易次数 | 743（0.78 笔/天） | 75（0.08 笔/天） |
| 胜率 | 47.5% | 57.3% |
| 最大回撤 | 13.13%（1331 USDT） | 2.03%（204 USDT） |
| Sharpe（日钱包口径） | -1.65 | -0.50 |
| 平均持仓时长 | 16.6 小时 | 25.6 小时 |
| 水下时长 | 约 2 年（几乎全程未创新高） | 约 2 年 |

## 解读

**1. 两个策略都输给了"什么都不做"。** 同期买入持有四个币平均赚 17.34%，两个策略一个亏 11.9%、一个亏 1.2%。这不是实现失误，而是基线策略的真实水平——经典指标组合在没有市场适配和成本优化的情况下，跑不赢基准是常态。这就是设计文档里"基线策略预期不赚钱"的实证。

**2. 手续费是趋势策略的头号杀手。** EmaRsi 交易 743 次，按 500 USDT 仓位和约 0.1%/边费率估算，累计手续费约 743 USDT——占总亏损 1190 USDT 的 **约 62%**。1h 级别的 EMA 金叉在震荡市反复打脸（whipsaw），每次错误信号都要交两次费。教训：**信号频率本身就是成本**。

**3. 回撤和交易次数比总收益更有信息量。**
- EmaRsi 回撤 13% 配上 -12% 收益，风险调整后（Sharpe -1.65）是明确的"负期望高波动"，直接淘汰。
- RsiMeanRevert 回撤仅 2%，亏损也小，本质是**极低敞口**：要求"价格站上 EMA200 且 RSI<30"的条件很少同时成立（2.6 年仅 75 次），大部分时间空仓。亏得少不等于策略好，但说明风控（保守入场 + protections + -6% 止损）确实把损失关在了笼子里。
- 75 次交易的样本量偏小，其胜率 57.3% 的统计置信度有限——样本量是评估任何回测结论的前提。

**4. 水下时间被普遍忽视。** 两个策略的资金曲线都在开局不久后见顶，之后约两年没有创出新高。真金白银跑这种策略，多数人撑不过 3 个月就会手动干预——**回撤持续时间是纪律的压力测试，属于策略可用性的一部分**。

## 结论与下一步

- 基线确认：流程闭环可用（数据→策略→回测→报告），策略本身不可用于实盘。
- 下一步（见 `02-overfitting-check.md`）：用样本内数据做 hyperopt 参数优化，再用从未参与优化的样本外数据检验——演示"优化后回测变好"有多少是真实改进、多少是过拟合幻觉。
