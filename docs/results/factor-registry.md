# 因子登记册（living doc）

每一个被检验的因子（含证伪的）都必须登记于此。多重检验校正（BH、DSR 的 n_trials）
按"市场家族内的登记数量"计算——不登记就检验，视为流程违规。

## 预登记评估协议（先于任何结果提交，不得因结果修改）

- 股池：美股 = S&P 500（点时成分若可得则用之，否则当前成分并声明幸存者偏差）；A 股 = 沪深 300 当前成分（同样声明）
- 频率：月末再平衡，五分层，等权
- 成本：10 bps/边 × 双腿 × 顶层换手率
- 指标：全样本 rank IC 均值与 t 值、置换检验 p（单侧，seed=42）、半年分段 IC 符号一致率、多空净收益、分层单调性
- 多重检验：市场家族内 BH（α=0.05）；DSR 的 n_trials = 该家族登记总数
- **通过标准（全部满足才算 PASS，进入 paper 候选）**：
  1. BH 校正后 IC 显著（置换 p 通过 BH）
  2. 半年分段 IC 符号一致率 ≥ 60%
  3. 多空净收益（扣成本）> 0
  4. 分层大体单调（层均值与层序号的 Spearman 相关 ≥ 0.8）
- 任何不满足 → REJECTED 或 INCONCLUSIVE（样本不足），如实登记

## 已知局限（预先声明）

- 美股样本约 3 年有效截面（4 年数据 - 12 个月形成期），统计功效有限；结论标注"初检"
- 幸存者偏差：现用成分回看历史，多头收益系统性偏乐观；PASS 的因子在 paper 阶段前须用更长样本 + 点时股池复检
