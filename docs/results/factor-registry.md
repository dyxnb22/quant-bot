# 因子登记册（living doc）

每一个被检验的因子（含证伪的）都必须登记于此。多重检验校正（BH、DSR 的 n_trials）
按"市场家族内的登记数量"计算——不登记就检验，视为流程违规。

## 预登记评估协议（先于任何结果提交，不得因结果修改）

- 股池：美股 = S&P 500（点时成分若可得则用之，否则当前成分并声明幸存者偏差）；A 股 = 沪深 300 当前成分（同样声明）
- 频率：月末再平衡，五分层，等权
- 成本：10 bps/边 × 双腿 × 顶层换手率
- 指标：全样本 rank IC 均值与 t 值、置换检验 p（单侧，seed=42）、半年分段 IC 符号一致率、多空净收益、分层单调性
- 多重检验：市场家族内 BH（α=0.05）；DSR 的 n_trials = 该家族登记总数
- **通过标准（全部满足才算 PASS，进入 paper 候选）**：
  1. BH 校正后 IC 显著（置换 p 通过 BH）
  2. 半年分段 IC 符号一致率 ≥ 60%
  3. 多空净收益（扣成本）> 0
  4. 分层大体单调（层均值与层序号的 Spearman 相关 ≥ 0.8）
- 任何不满足 → REJECTED 或 INCONCLUSIVE（样本不足），如实登记

## 已知局限（预先声明）

- 美股样本约 3 年有效截面（4 年数据 - 12 个月形成期），统计功效有限；结论标注"初检"
- 幸存者偏差：现用成分回看历史，多头收益系统性偏乐观；PASS 的因子在 paper 阶段前须用更长样本 + 点时股池复检

## 冻结登记（2026-08-12，先于任何后续运行提交）

**CN 动量组合参数冻结**：momentum_12_1 + 缓冲带(进20/出40) + 行业中性 + 月度调仓。
2016-08~2026-08 十年样本退役（不再用于任何择优/比较/调参，代码护栏 FROZEN_OVERRIDE）；
前向验证唯一来源 = `docs/research/cn-momentum/forward-ledger.jsonl`（append-only，入库）。
研究 PASS ≠ 部署 PASS：部署另过 Deployment Gate（G1 DSR≥0.95 / G2 基准超额>0 /
G3 IR≥0.3 / G4 成本翻倍净夏普>0 / G5 前向≥12 个月度周期），见迭代 v3/v4 计划。

**口径声明（第二轮审计 P1-07/08）**：11 号 PASS 的对象是"全市场 qcut 五层多空"研究口径；
冻结部署候选是"行业内 rank-pct 缓冲长仓"——不同目标函数，PASS 不外推，候选资格由前向账本
自证。行业中性 = 行业内数量中性 + 当前行业快照（存在回放期行业漂移误差，PIT 行业为付费触发项）。

**试验计数机读化**：`registry.json` 为 DSR/多重检验的唯一分母来源（只增不减），
评估流水线无手工覆盖入口；协议 v3 起显著性以 Newey-West p 为准（置换 p 降为信息列）。

## 协议 v4 修订（2026-08-13 预登记，先于实现提交）

动机：基本面批次的真实数据暴露三个披露盲区（20 号 PASS 不可实施靠人工注记、
截尾动量样本静默塌缩 39→19 月、22 号 INCONCLUSIVE 无功效刻画）。
**性质：纯披露增强，不改变任何 PASS/INCONCLUSIVE/REJECTED 的判定标准；
对既有报告为追溯标注（重渲染），不消耗试验计数。**

1. **可实施性标注**：满足 PASS 标准但多头腿（Q5 层）月均收益 ≤0 的，判定文字
   自动标注"研究性 PASS——多头腿为负不可实施，不产生候选"（此前靠人工注记）。
2. **样本塌缩警报**：因子有效月数 < 宇宙可用月数（≥50 名/月）的 70% 时，
   报告自动附加警示（留存窗口可能有行情偏斜）。
3. **功效估计**：INCONCLUSIVE 判定自动附"效应保持下约需 N 月总样本可分辨"
   （N = 月数 × (1.645/NW t)²，向上取整）。

执行记录（2026-08-13）：三项已实现（含回归测试），20/22 号报告重渲染完成——
20 号自动标注"研究性 PASS 不可实施"+ 塌缩警报（19/52 月 = 37%）；22 号功效估计
（约需 120 月 vs 现有 119 月）。配套新增：点时可信度审计（23 号，三数据域 0 硬违规，
pubDate 滞后中位 31 天 / EDGAR 首次申报滞后中位 36 天；数据源回填更正值的情形
本审计无法检出，declared 为残余风险）；日检接管临时任务监控（多晚续传静默失败可被发现）。

## 稳健性披露登记（2026-08-12 预登记，先于运行提交）

目的：加固现有 5 个 PASS 的置信刻画，**不产生任何择优/切换/判定变更**。

1. **块自助置换 p**（moving-block 符号翻转，块长 6 个月）：对 5 个 PASS 因子的 IC 序列
   补充计算，作为 NW-p 的稳健性对照列。判定协议不变（仍以 NW-p 过 BH 为准）。
2. **参数平原披露**：三候选的标准规则在 enter∈{15,20,25}% × exit∈{35,40,45}% 邻域内
   的可交易口径净夏普矩阵。**预登记约束：仅披露刀锋/平原形态，任何点位不得因此被选用**；
   冻结参数（20/40）维持不变。

- 结果（2026-08-12 执行）：5/5 因子块自助 p < 0.05（最大 0.02，显著性不依赖逐点独立假设）；
  三候选 9 点邻域净夏普全正（冻结点均在平原上，非刀锋）。无判定/参数变更。
