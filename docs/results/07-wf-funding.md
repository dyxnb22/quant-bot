## 读法

1. 只有当 OOS 拼接收益为正、且多数窗口 OOS 为正时，参数化流程才算有泛化能力。
2. IS 好看 + OOS 难看 = 过拟合；IS/OOS 都难看 = 策略本身无效。
3. 任何单窗口的好结果都不构成上线依据。

## 人工解读：首个 K 线外信息源的检验结论

**背景与数据工程**（本轮的持久资产）：
- OKX 费率 API 实测只保留约 3 个月（2026-05-11 起），不足以支撑研究，已排除；
- 改用 Binance Vision 月度归档（2023-01 起完整，静态文件不受 API 地区限制）+ OKX 补最近尾部，每对 4079 条、覆盖与 K 线完全对齐；
- 对齐采用 backward merge_asof + 滚动 z-score 逐期只用历史，两处均有专项测试锁死无未来函数。

**一次透明的中途修正**：预登记论点用"绝对 bps 阈值"定义极端，分布统计显示它跨时代失效（BTC 2023-2026 全期最低仅 -1.5bps，2021-2022 时代的 -30bps 已绝迹），导致零交易。在**未看任何 OOS 结果**的前提下改为滚动 z-score（90 期 ≈ 30 天）的相对极端定义，论点不变、预登记标准不变。

**结论：论点被强证伪。** 这次连"过拟合幻觉"都没有——7/10 窗口样本内就是负收益，优化器在可以随意挑阈值的开卷条件下都做不出利润。IS→OOS 衰减 +0.68% 不是泛化好，而是样本内已在噪声地板上。"负费率极端 → 现货逆向做多"在 2023-2026 的这四个币对上没有可提取的 alpha：负费率极端大多出现在下跌趋势中，做多接刀的亏损吃掉了情绪反弹的收益。

**边界说明**：本结论只否定"费率极端逆向做多现货"这一种用法。费率数据的其他用法属于不同论点：作为价格信号的组合特征、期货端收正费率的 carry 策略（需合约交易，超出现货范围）、跨币种截面排序等——数据管道已就绪，未来可低成本检验。
