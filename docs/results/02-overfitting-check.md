# 过拟合检验：样本内优化 → 样本外验证

- 日期：2026-08-12
- 策略：EmaRsiStrategy
- 方法：hyperopt（SharpeHyperOptLoss，60 轮，优化空间 buy/roi/stoploss）只允许看 **样本内** 数据；用从未参与优化的 **样本外** 数据检验参数的真实泛化能力。
- 切分：样本内 2023-06-01 → 2025-06-01（约 2 年）；样本外 2025-06-01 → 2026-08-11（约 1 年 2 个月）

## 优化产出的参数（存于 `EmaRsiStrategy.json`）

| 参数 | 原始值 | 优化后 |
|---|---|---|
| buy_rsi_max | 70 | 60 |
| minimal_roi | 0.10 / 0.05 / 0.02 / 0（递减） | 0.647 / 0.212 / 0.069 / 0 |
| stoploss | -0.08 | **-0.234** |

**第一个警报在看回测结果之前就出现了**：优化器把止损放宽到 -23.4%、把首档止盈提到 64.7%——本质是"几乎不止损、拿住等大涨"。这在牛市样本内必然好看，但它交换来的是单仓最大 23% 的亏损容忍，已经违反了本项目的风险政策（测试断言止损不深于 -20%）。**优化器没有风险观，它只优化你给的目标函数。**

## 样本内 vs 样本外

| 指标 | 样本内（参与优化） | 样本外（未参与） |
|---|---|---|
| 总收益 | **+0.70%** | **-2.78%** |
| Sharpe（日钱包口径） | 0.18 | -1.27 |
| 交易次数 | 302 | 162 |
| 最大回撤 | 2.51% | 3.96% |
| 同期市场 | **+325.06%**（大牛市） | **-42.62%**（深熊） |

## 解读

**1. 表现衰减是实锤的。** 样本内勉强为正（Sharpe 0.18），样本外转负（Sharpe -1.27）。用样本内回测数字去外推未来收益，会系统性高估——这就是"回测很美、实盘就亏"的机制。

**2. 但这份数据里还叠加了另一个变量：市场体制（regime）翻转。** 样本内是 +325% 的牛市，样本外是 -42.6% 的熊市。单次切分无法区分"参数过拟合"和"策略只适应牛市"——两者都存在。严谨做法是 **walk-forward**：多个滚动窗口反复"优化→前推验证"，把体制依赖暴露出来（列入阶段二）。

**3. 一个反直觉的亮点：样本外市场跌 42.6%，策略只亏 2.78%。** 趋势过滤 + protections 在熊市里大部分时间空仓，躲过了主跌浪。这不是"策略赚钱"，而是"风控在极端行情下控制了暴露"——风控价值和策略 alpha 是两回事，评估时必须分开记账。

**4. 运维陷阱：`EmaRsiStrategy.json` 会在运行时静默覆盖策略类里的参数。** 代码里写着 stoploss=-0.08，实际跑的是 -0.234。生产环境必须把参数文件纳入版本控制并在部署清单中显式核对（本仓库已将其入库）。

## 方法论结论

1. 任何"优化后"的回测指标，只有样本外数字才有参考价值。
2. 优化目标函数必须内嵌风险约束（如限制止损搜索空间、用含回撤惩罚的损失函数），否则优化器会卖掉你的风险政策去买夏普。
3. 单次 IS/OOS 切分是最低标准；上生产前要 walk-forward + 多体制覆盖。
4. 本策略（含优化参数）**不具备实盘价值**，维持 dry-run 用途。
