# 多市场量化研究平台路线图（总清单）

日期：2026-08-12 | 状态：进行中（本文档为持续追踪的唯一清单，完成即勾选）

## 战略定位（本轮讨论的共识）

本项目从"加密货币机器人"升级为**多市场量化研究平台**：quantlab 方法论层（walk-forward、预登记决策、风险政策、数据质量、统计检验、LLM 辅助）市场无关；每个市场是一个"数据管道 + 回测器 + 执行器"插件。币市系统保持运行，作为第一个执行器与前向数据积累。

市场优先级（预登记，不因中途结果动摇）：**美股（研究+paper）→ A 股（纯研究搭车）→ 港股（缓议）**。多市场复制只发生在"第一个稳健因子"出现之后。
